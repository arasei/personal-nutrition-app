# Nutriflecta

食生活や生活習慣を振り返り、栄養素の傾向と食生活を見直すヒントを確認できるWebアプリ

[アプリURL](https://nutriflecta.vercel.app)




## Nutriflectaについて

- Nutriflectaは、食生活や生活習慣に関する質問への回答をもとに、栄養素の傾向を可視化し、食生活を見直すきっかけを提供するWebアプリです。

- 結果はレーダーチャートやランキングで確認でき、回答から不足傾向が示された栄養素に応じた食品・料理・生活習慣のヒントを表示します。また、過去の診断結果を保存し、前回からの変化を振り返ることができます。

- 本サービスは、質問への回答に基づく食生活の振り返りを目的としています。スコアは実際の栄養摂取量の測定値ではなく、医学的な診断を行うものではありません。




## 開発背景

食生活を改善したいと思っていても、「自分の食生活にはどのような傾向があるのか」「何から見直せばよいのか」が分からず、行動を起こせなかった経験がありました。
そこで、身近な食生活や生活習慣についての質問に答えることで、自分の傾向を把握し、具体的な食品や料理の選択につなげられるサービスを目指しました。
一度結果を確認するだけでなく、過去の結果と比較できるようにすることで、継続的に食生活を振り返るきっかけを作りたいと考えました。




## 主な機能

- **ユーザー登録・認証**：メールアドレスとパスワードによる新規登録、確認メールによるメールアドレスの確認、ログインに対応しています。

- **質問形式の栄養診断**：食生活や生活習慣に関する質問への回答をもとに、栄養素ごとのスコアを算出します。

- **診断結果の可視化**：栄養素ごとの傾向を、レーダーチャートやランキングで表示します。

- **食生活を見直すヒントの表示**：回答から不足傾向が示された栄養素に応じて、食品・料理・生活習慣の見直し候補を表示します。

- **診断履歴の保存・閲覧**：完了した診断結果をアカウントごとに保存し、履歴一覧から過去の結果を確認できます。

- **前回の結果との比較**：前回と今回のスコアを比較し、回答に基づく傾向の変化を振り返れます。

## 技術選定の経緯

## AI・デザインツールの活用について

動作確認は自分で行い、画面操作とPrisma Studioによるデータ確認を実施しました。確認内容は、以下の「動作確認」に記載しています。



## 動作確認
以下の内容を手動で確認しました。

- **診断の一連の操作**：質問への回答から診断結果の表示まで進められることを確認しました。

- **履歴詳細の再表示**：履歴詳細ページを再読み込みしても、同じ診断結果が表示されることを確認しました。

- **アカウント切り替え時の履歴表示**：確認に使用したアカウント間で、別アカウントの診断結果が履歴に混在しないことを確認しました。

- **診断中断後の動作**：診断途中でトップページに戻った後、新しい診断を開始して最後まで進められることを確認しました。

- **回答の保存状態**：Prisma Studioを使用し、中断した診断の回答がDBに保存されていることを確認しました。
